# Security reporting

Do not include credentials, signing keys, production data or exploitable details
in public issues. For sensitive reports contact the maintainer at
**ivan@infocusmode.com**, the address published in the project's Maven metadata.
Provide affected versions and a minimal sanitized reproduction. No response-time
SLA is promised.

Normal contributors do not need release credentials. Keep local credential files
out of commits, Docker build contexts and test artifacts. Follow [PUBLISHING.md](PUBLISHING.md)
for the separate maintainer release process.

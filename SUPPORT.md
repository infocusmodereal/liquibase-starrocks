# Support

Use [GitHub issues](https://github.com/infocusmodereal/liquibase-starrocks/issues)
for reproducible defects and focused feature requests. This is a community
project; there is no guaranteed response time or commercial support commitment.

Compatibility is scoped to the exact published records and their named
capabilities. Unlisted combinations are unverified. Historical test coverage
does not imply that an upstream version is still maintained. Any planned
removal of a tested baseline must be announced in release notes before its
regression job is removed.
